# Cinematic Density

Use when a user wants cinematic impact without sacrificing retrieval or reading efficiency.

## What to inspect

- framing and focal hierarchy
- changes in visual scale
- transitions between quiet and dense moments
- reveal timing
- crop and composition
- controlled negative space
- how secondary information recedes

## Why it matters

Cinematic design is about rhythm and attention, not dark backgrounds, oversized typography, or gradients.

## Design question

> Where should the interface ask the user to look, pause, move, and then resume scanning?

## Use with

- story-driven homepages
- portfolios and archives
- product storytelling
- immersive knowledge experiences

## Failure mode

If cinematic treatment makes search, scanning, or navigation slower without meaningful benefit, reduce it on utility surfaces.
