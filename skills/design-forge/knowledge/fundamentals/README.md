# Design Fundamentals

This directory contains durable design principles that can improve agent judgment across products and visual styles.

The goal is not to reproduce a design-school textbook. Each module should turn a principle into something an agent can reason with.

## Knowledge format

Each principle should answer:

1. **Principle** — what it is.
2. **Why** — why it affects perception, comprehension, or experience.
3. **Recognition** — how to notice it in a design problem.
4. **Question** — how to discuss it with a non-designer.
5. **Decision** — what design choice it can inform.
6. **Action** — how to apply it.
7. **Critique** — how to detect misuse.

## Current foundation

- `visual-hierarchy.md` — control of attention and relative importance.
- `gestalt.md` — grouping, perception, figure/ground, similarity, proximity, continuity, closure.
- `composition.md` — balance, scale, contrast, alignment, rhythm, whitespace, focal points.

## Design education basis

The foundation intentionally follows a pattern visible in established graphic-design education: formal and sensory principles are taught alongside communication, systems, and problem solving. RISD's BFA Graphic Design curriculum, for example, explicitly covers form, image, color, typography, visual systems, information design, and communication theory. citehttps://www.risd.edu/academics/graphic-design/bachelors-program

This repository is an agent-oriented synthesis, not a reproduction of any school's curriculum.

## Source philosophy

Prefer:

1. original research or established theory
2. university curricula and teaching material
3. mature design-system documentation
4. reputable design-education sources

Do not turn a single blog post or trend report into a universal rule.
