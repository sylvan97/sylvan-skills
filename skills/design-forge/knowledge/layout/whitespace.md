# Whitespace

## Principle

Empty space is an active layout tool. It separates, groups, slows, emphasizes, and creates rhythm.

## Trigger

Activate when a page feels cramped, visually flat, or unnecessarily fragmented; also when the user requests premium, calm, editorial, or cinematic qualities.

## Non-designer question

> 你希望页面更“呼吸感强”，还是希望尽可能多的信息同时出现在眼前？

## Decision

Use space according to relationships and hierarchy, not as a universal premium aesthetic. Related elements generally need tighter relationships than unrelated sections.

## Specification implications

Define semantic spacing roles for:

- control internals
- related content
- component sections
- page sections
- major composition breaks

## Verification

Check whether spacing makes grouping and hierarchy easier to perceive. If removing a gap destroys meaning, it was functional rather than decorative.

## Common failures

- equal spacing everywhere
- large empty areas without compositional purpose
- adding cards and borders to compensate for missing spacing logic
- shrinking whitespace on mobile without checking hierarchy
