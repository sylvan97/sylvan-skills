# Anti-Generic Gate

This gate exists because a polished interface can still be creatively empty.

## Hard rejection

Reject and regenerate a concept when:

- three candidates differ only in palette/type/layout decoration;
- the concept is essentially a standard SaaS dashboard, portfolio, blog, landing page, or card grid with a new theme;
- its thesis contains only style adjectives;
- its primary interaction is indistinguishable from ordinary browsing;
- the user's content has not influenced the experience model;
- the concept relies on hero imagery to create all of its personality;
- the concept would look substantially the same after replacing its copy with placeholder content.

## Distinctiveness test

Score each concept 0–2:

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Mental model | generic | lightly reframed | clearly distinct |
| Information behavior | conventional | modified | transformed |
| Signature interaction | none | decorative | essential |
| Content transformation | generic | partially adapted | content drives experience |
| Spatial language | template-like | some identity | unmistakable |
| Temporal/motion language | absent | decorative | communicates meaning |
| Memorability | forgettable | recognizable | immediately distinctive |

A concept should normally score **10+ / 14**. Any score of 0 in Mental model, Information behavior, or Signature interaction requires regeneration.

## Anti-AI-slop review

Before showing a concept to the user, ask:

> If another model received the same prompt, would this be one of its first five answers?

If yes, push one level deeper.

## Escalation ladder

If concepts remain generic:

1. Remove the UI category from the prompt.
2. Search outside web UI for references.
3. Change the mental model.
4. Change the navigation model.
5. Change the content representation.
6. Introduce a deliberate contradiction.
7. Generate a hybrid from two incompatible strengths.

Do not simply add more gradients, animation, 3D, glass, or oversized typography. Those are visual effects, not concepts.
