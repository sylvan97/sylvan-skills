# ACG / Workbench References

Use when the user wants anime, manga, visual-novel, game, mecha, cyberdeck, otaku desktop, or fictional-system qualities.

## What to inspect

- diegetic interface: controls that belong to the fictional world
- game HUD information hierarchy
- command-center and workstation metaphors
- manga panel composition
- visual-novel scene transitions
- system-state language
- character/identity as an information anchor
- technical annotation and Japanese editorial conventions

## Why it matters

ACG influence should change the user's mental model and interaction language, not merely add anime imagery, neon, glow, kana, or HUD decorations.

## Design question

> What would this interface actually be if it existed inside the user's fictional or cultural world?

## Workbench transformation examples

- article → recovered document / log
- project → mission
- search → scanner
- settings → calibration
- navigation → terminal / command deck
- category → classification system

## Responsive principle

Preserve the workstation mental model while changing composition by viewport. A mobile experience may become a focused surface plus a command drawer rather than a shrunken desktop.

## Failure mode

Black + cyan/magenta + Japanese characters + random HUD lines is a visual trope, not a concept.
