# Spatial Navigation

Use when content relationships, discovery, maps, canvases, or collections are more important than a linear list.

## What to inspect

- spatial grouping
- zoom levels
- progressive disclosure
- clusters and paths
- local versus global context
- detail-on-selection
- keyboard and mobile alternatives

## Why it matters

A spatial model can turn relationships between content into navigation instead of hiding them behind filters and pagination.

## Design question

> Would seeing where an item lives relative to other items help the user understand or discover it?

## Failure mode

Do not use a map merely because it looks impressive. If the spatial relationship does not improve the task, use a simpler information structure.
