# 默认风格方向库 · 5 套内置方案

> 本文件是 `danqing-figma-forge` 的内置「默认外观」候选库。当用户**不想从自己的 token 源起步**（无 fileKey、**不用中国色**、或明确要"开箱即用的默认风格"）时，从这里挑 3-5 套做 Step 5 的差异化方向，而不是从零瞎编。
>
> **与中国色 / 通用基线并列共存**：有源 token（中国色 JSON 或用户 Figma 库）时仍优先用源；本库是"没有源、或要新默认外观"时的快捷起点。二者不冲突。
>
> 每套均已在可视化样例里渲染出配色 / 字体 / 按钮 / 输入 / 卡片样张，直接用 `present_files` 给用户看全貌：
> - `references/default-styles-proposal.html` → 方案 01–04
> - `references/aristotle-green-scheme.html` → 方案 05

## 使用约定

- 五套各自有完整独立的配色，属于 **palette / mood 方向**（而非布局骨架方向）。Step 5 出方向时，可把它们作为「配色 + 质感」起点，再叠加布局 / 排版 / 动效的差异。
- 全部满足 **WCAG AA 正文对比度**；状态不以颜色单独传达（辅以文字 / 图标）；动效尊重 `prefers-reduced-motion`。
- 用户选中某套后，按该套 palette 重建 token 表（变量名 → 值 → 类型 → 用途），与原 Step 8「写入规格」流程无缝衔接。
- 图标一律用 SVG 矢量（inline `<svg>`），绝不用 emoji 字符（见核心约束 4）。

## 方案 01 · 报章活字 Editorial Ink（浅色）

- **mood**：极简 / 编辑级 / 权威 / 克制
- **明暗**：Light（浅色为主）
- **配色**：

| 角色 | hex | 用途 |
|---|---|---|
| 纸底 bg | `#F7F4EC` | 暖白纸底，替代纯白，长读更耐看 |
| 墨色 ink | `#1A1714` | 正文 / 标题 |
| 信号红 signal | `#E2402A` | 仅作信号色：栏目分隔线、关键按钮、强调数字 |
| 灰褐 muted | `#8A8175` | 次要文字 |
| 米褐 rule | `#D9D2C5` | 发丝规线 / 卡片描边 |

- **字体**：衬线大标题（`"Songti SC","Noto Serif SC",serif`）+ 等宽标注（`ui-monospace`）建立"印刷"语感；正文用系统无衬线。
- **关键质感**：① 暖纸底替代纯白；② 衬线标题 + 等宽元数据；③ 红色极少量，只承担信号；④ 发丝级规线（hairline rule）切分区块，克制不喧哗。
- **哲学依据**：印刷 / 编辑设计语言——清晰优于装饰、留白与规线建立秩序。
- **适用场景**：内容类产品（CMS / 文档 / 博客 / 后台）最稳妥的底；系统字体即呈现，零素材依赖。
- **源文件**：`references/default-styles-proposal.html`（Scheme 01）

## 方案 02 · 暗金极简 Obsidian Luxe（深色）

- **mood**：高级 / 科技感 / 克制奢华 / 材质感
- **明暗**：Dark（深色为主；可作为方案 05 的暗色基底复用）
- **配色**：

| 角色 | hex | 用途 |
|---|---|---|
| 近黑底 bg | `#0E0E10` | 页面底 |
| 表面 surface | `#16161A` | 卡片 / 表面 |
| 香槟金 gold | `#C9A86A` | 关键描边、主按钮、焦点环（唯一金属色） |
| 边框 border | `#2A2A30` | 描边 / 分隔 |
| 文本 text | `#EDEAE3` | 正文 |

- **字体**：系统无衬线；标题可加 `letter-spacing` 立住精致感。
- **关键质感**：① 近黑底 + 单一香槟金；② 1px 金色发丝线切分区块，替代粗边框；③ 金色只用于关键描边 / 主按钮 / 焦点环，其余皆墨阶灰；④ 大量负空间靠留白与材质感立住高级调性。
- **哲学依据**：材质与留白 > 装饰；单一金属强调久看不腻，任何品类不违和。
- **适用场景**：高端品牌、金融、媒体夜间场景；高对比正文满足 AA。
- **源文件**：`references/default-styles-proposal.html`（Scheme 02）；其暗色语言被方案 05 直接复用。

## 方案 03 · 瑞士网格 Swiss Grid（浅色）

- **mood**：极简 / 专业 / 国际主义 / 秩序
- **明暗**：Light（浅色）
- **配色**：

| 角色 | hex | 用途 |
|---|---|---|
| 纯白 bg | `#FFFFFF` | 页面底 |
| 近黑 ink | `#0A0A0A` | 正文 / 标题 |
| 克莱因蓝 blue | `#1A2BDD` | 强调与链接（唯一彩色） |
| 网格线 grid | `#ECECEC` | 24px 模数网格线 |
| 灰 gray | `#555555` | 次要文字 |

- **字体**：超大紧排无衬线标题（`font-weight:800; letter-spacing:-.02em`），字号即层级；正文系统无衬线。
- **关键质感**：① 纯白 + 近黑 + 克莱因蓝，最稳的"设计系统"底色；② 24px 模数网格贯穿，区块用规线对齐；③ 蓝色只作强调与链接，其余纯黑白；④ 结构即风格，不靠装饰。
- **哲学依据**：国际主义排版（Swiss / International Typographic Style）——网格、客观、克制。
- **适用场景**：后台、SaaS、文档、官网；专业且不无聊，零素材依赖。
- **源文件**：`references/default-styles-proposal.html`（Scheme 03）

## 方案 04 · 果酱撞色 Jam Pop（浅色奶油）

- **mood**：活泼 / 友好 / 有态度 / 贴纸手感
- **明暗**：Light（浅色奶油）
- **配色**：

| 角色 | hex | 用途 |
|---|---|---|
| 奶油底 bg | `#FFFDF6` | 托住三色果酱块，不脏不花 |
| 草莓红 red | `#FF4D5E` | 警示 / 强调 |
| 蓝莓蓝 blue | `#3A6FF7` | 主操作 |
| 芒果黄 yellow | `#FFB020` | 信息 |
| 墨黑 ink | `#14110D` | 粗描边 / 文字 |

- **字体**：圆润友好的系统无衬线；标题可加粗。
- **关键质感**：① 实色硬阴影（solid offset shadow，无模糊偏移），像贴纸有手感；② 粗黑描边 + 粗圆角；③ 三色分工明确（红=警示/强调、蓝=主操作、黄=信息），秩序清晰；④ 撞色只用在块与按钮。
- **哲学依据**：新粗野 / 贴纸美学——友好、可亲、不幼稚；硬阴影是纯 CSS 盒阴影（无模糊），渲染便宜。
- **适用场景**：消费 / 教育 / 工具类产品；儿童与成人都亲和；状态不靠颜色单独传意（红/蓝/黄分工 + 文字）。
- **源文件**：`references/default-styles-proposal.html`（Scheme 04）

## 方案 05 · Aristotle Warm + Green（双模）

- **mood**：温暖 / 人文 / 自然 × 理性 / 专注
- **明暗**：**双模**（Light = Aristotle 暖底 + 绿；Dark = 黑金 + 绿）；两模共享同一支绿色家族。
- **来源**：亮色提取自 heyaristotle.com（CSS chunk 实测非推测）；暗色复用方案 02 的黑金语言。
- **亮色配色**：

| 角色 | hex | 用途 |
|---|---|---|
| 纸白 bg | `#fdfdf7` | 页面底 |
| 奶油 cream | `#f9f4e8` | 次级表面 |
| 米褐 beige | `#e9ddc8` | 描边 / 分隔 |
| 浓缩咖啡 espresso | `#362416` | 正文（14.5:1 ✓） |
| 灰褐 taupe | `#6b5d4f` | 次要文字（6.2:1 ✓） |
| 祖母绿 primary | `#157a4a` | **新增主强调**：主操作（5.25:1 ✓） |
| 深绿 strong | `#0f5c38` | 深绿 / 链接 hover |
| 柔绿 soft | `#8ec777` | 绿填充 / 成功底 |
| 薄荷 mint | `#d1fae5` | 浅绿背景 |
| 金 gold | `#c9a86a` | 浅色仅作装饰发丝线 / 描边（浅底 2.1:1，禁作正文） |
| 酒红 error | `#d42b44` | 警示（大字号 / 图标 / 填充，浅底 4.4:1） |

- **暗色配色**：

| 角色 | hex | 用途 |
|---|---|---|
| 近黑底 bg | `#0e0e10` | 页面底 |
| 表面 surface | `#17171a` | 卡片 / 表面 |
| 文本 text | `#ececec` | 正文（16.3:1 ✓） |
| 边框 border | `#2a2a2e` | 描边 / 分隔 |
| 绿辉光 primary | `#46c98b` | 主操作辉光（9.2:1 ✓） |
| 深绿 strong | `#1f9d5c` | 链接 hover |
| 绿暗填充 soft | `#0f3d28` | 成功底 |
| 金 gold | `#c9a86a` | 描边 / 焦点环 |
| 酒红浅 error | `#e06a7a` | 警示 |

- **字体**：系统无衬线（PingFang SC / system-ui）；人文温度靠配色而非衬线。
- **关键质感**：① 暖奶油 + 浓缩咖啡棕的"编辑级温度"（来自 heyaristotle）；② **祖母绿**为主角，从"怀旧暖棕"跳成"自然 × 理性"，多一层生长 / 专注语义；③ 金色发丝线作装饰（浅底仅装饰，不作正文）；④ 暗色用黑金立高级感，绿光作唯一呼吸点；⑤ 双模通过同一支绿色家族无缝切换。
- **哲学依据**：人文温度 × 自然理性；状态语义明确（绿=主/成功、金=装饰、酒红=警示）。
- **适用场景**：教育 / 辅导类产品；需要亮暗双模且一键切换的项目。
- **Token 表（DTCG 语义层）**：完整版见 `references/aristotle-green-scheme.html` 第 3 节，已通过 WCAG 2.1 校验，可直接照搬为写入规格的 token 来源。
- **源文件**：`references/aristotle-green-scheme.html`（Scheme 05）

## AI 执行提示（Step 5 落地方向库时）

1. **判断基线**：用户有 fileKey / 用中国色 → 走源 token 流程，本库仅作 mood 参考；用户无源 / 不用中国色 / 要默认外观 → 从本库挑 3-5 套出方向。
2. **挑方向**：按用户 mood 关键词从速览表选（如"温暖"→ 05，"极简专业"→ 03，"高级暗色"→ 02）。每套在「配色 + 质感」维度拉开差异，再叠加布局 / 排版 / 动效差异，避免只是换色。
3. **复用源文件**：用 `present_files` 打开上面两个 HTML，让用户直接看 5 套全貌对比，再 AskUserQuestion 选方向 / 融合。
4. **锁定后建 token 表**：以选中套的配色重建语义 token（变量名 → 值 → 类型 → 用途），与原 Step 8 写入规格 1:1 衔接。
