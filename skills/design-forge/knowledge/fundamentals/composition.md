# Composition

## Principle

Composition is the deliberate arrangement of visual elements so that the whole experience has structure, rhythm, emphasis, balance, and a readable path.

Composition is broader than a grid. A grid can support composition, but it does not create a meaningful composition by itself.

## Core principles

### Alignment

Alignment creates order and relationships. Shared edges and axes can make separate elements feel intentionally connected.

**Question:**
> Should this feel tightly organized, or intentionally free?

### Balance

Balance concerns how visual weight is distributed.

It can be:

- symmetrical
- asymmetrical
- radial
- intentionally unstable

Asymmetry is not automatically more creative. Symmetry is not automatically more boring.

### Scale

Scale creates hierarchy, depth, and emphasis. A large object can dominate a composition even without strong color contrast.

**Question:**
> Should this moment feel intimate, normal-sized, or monumental?

### Contrast

Contrast creates distinction and emphasis through differences in properties such as:

- size
- value
- color
- shape
- density
- texture
- motion
- spatial position

Good contrast is selective. If everything contrasts with everything else, nothing is clearly dominant.

### Whitespace / negative space

Empty space is an active compositional element. It can separate concepts, slow reading, establish hierarchy, create focus, and change perceived density.

**Question:**
> Should the content feel packed together or given room to breathe?

### Rhythm

Repeated elements and changing intervals create visual rhythm. Rhythm can be regular, alternating, progressive, or intentionally interrupted.

It is particularly useful for long pages and editorial experiences because repetition creates continuity while variation prevents monotony.

### Focal point

A focal point gives the viewer an entry point into a composition.

A page can have multiple focal points, but their relative priority should be intentional.

## Composition as a system of tensions

Instead of asking for a named style, reason through tensions:

```text
ordered ↔ free
symmetric ↔ asymmetric
sparse ↔ dense
static ↔ dynamic
uniform ↔ varied
centered ↔ directional
predictable ↔ surprising
```

These are not binary style categories. They are useful for identifying what the user is trying to balance.

## Recognition

If a page feels generic even though its components are polished, inspect composition:

- Are all sections built from the same card pattern?
- Is there a meaningful change of scale?
- Does the page have a clear visual rhythm?
- Are there memorable moments of composition?
- Is whitespace intentional or merely leftover?
- Does the layout respond to the content or force every section into the same template?

## Action

Before polishing components, create a rough composition using only:

- major text blocks
- major imagery
- containers
- whitespace
- primary actions

If the composition does not work at this level, component polish will not solve it.

## Critique

Temporarily remove color and decorative effects. Then ask:

- Does hierarchy still work?
- Is the reading path understandable?
- Does the page have rhythm?
- Are visual weights balanced intentionally?
- Does the composition have a reason to exist beyond being a collection of components?

## Agent rule

Do not start by filling a standard grid. Start by understanding the content's hierarchy and desired experience, then select a structural system that supports it.
