# Diegetic UI

Use when interface and world-building should feel inseparable.

## What to inspect

- whether controls have an in-world explanation
- how terminology changes the user's mental model
- how state is represented by the fictional system
- how navigation can become part of the fiction
- how visual hierarchy remains usable despite world-building

## Why it matters

Diegetic UI is one of the strongest ways to avoid generic themed UI. Instead of putting a visual skin on ordinary controls, redesign the control language itself.

## Design question

> If this interface existed inside the user's world, what would its controls actually be called and how would they behave?

## Good use

- A personal knowledge base as an operating console
- A research archive as an investigation system
- A travel journal as a field terminal
- A creative portfolio as a production workstation

## Failure mode

World-building must not obscure basic orientation, accessibility, or task completion.
