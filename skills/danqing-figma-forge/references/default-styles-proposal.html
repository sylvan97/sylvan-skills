默认视觉风格方案 · 4 套提案

目标：重新设计一套「默认风格」，既要有鲜明记忆点、敢于突破保守安全，又要保留默认风格应有的普适性与开箱即用。以下 4 套方向各异，均可在亮/暗主流场景直接套用，不依赖任何外部素材。

Scheme 01

报章活字 · Editorial Ink

把"默认"做成一本讲究的印刷品。暖白纸底 + 近黑墨色，只用一道信号红承担所有强调；标题用衬线建立权威，元数据用等宽字体标注，像报纸的栏目分隔线一样用细规线切分区域。

核心视觉特征

  • 暖纸底 #F7F4EC 替代纯白，长时间阅读更耐看
  • 衬线大标题（宋体/Noto Serif）+ 等宽标注，形成"印刷"语感
  • 红色仅作信号色：栏目分隔线、关键按钮、强调数字
  • 发丝级规线（hairline rule）切分区块，克制不喧哗
为何能当默认：暖纸+墨色是内容类产品最稳妥的底；信号红用量极少，不会审美疲劳；系统字体即可呈现，零素材依赖，CMS / 文档 / 后台都能直接套。

Scheme 02

暗金极简 · Obsidian Luxe

把"默认暗色"做成一块被打磨过的黑曜石。近黑底 + 香槟金发丝线，金色只用于关键描边、主按钮与焦点环；大量留白与极细分割线，营造克制的奢华感。

核心视觉特征

  • 近黑底 #0E0E10 + 香槟金 #C9A86A 单一金属色
  • 1px 金色发丝线切分区块，替代粗边框
  • 焦点环 / 主按钮用金，其余皆墨阶灰
  • 大量负空间，靠留白与材质感立住高级调性
为何能当默认：中性暗底 + 单一金属强调，任何品类都不违和；金色用量极少，久看不腻；高对比正文满足 AA，适合高端品牌、金融、媒体夜间场景。

Scheme 03

瑞士网格 · Swiss Grid

把界面交给国际主义排版。纯白底 + 近黑字 + 一道克莱因蓝，严格模数网格与超大无衬线标题，靠结构与字号建立秩序，不靠装饰。

核心视觉特征

  • 纯白 #FFFFFF + 近黑 #0A0A0A + 克莱因蓝 #1A2BDD
  • 24px 模数网格贯穿，区块用规线对齐
  • 超大紧排无衬线标题，字号即层级
  • 蓝色只作强调与链接，其余纯黑白
为何能当默认：黑白蓝是最稳的"设计系统"底色，网格让任何布局都立得住；无衬线系统字体即呈现，零素材；后台、SaaS、文档、官网皆可套，专业且不无聊。

Scheme 04

果酱撞色 · Jam Pop

把"默认"做得像一张手感贴纸。奶油底上三色果酱块（草莓红 / 蓝莓蓝 / 芒果黄）大胆并列，所有可点元素带实色硬阴影（无模糊偏移），粗圆角、粗黑描边，友好但有态度。

核心视觉特征

  • 奶油底 #FFFDF6 托住三色果酱块，不脏不花
  • 实色硬阴影（solid offset shadow）：像贴纸，有手感
  • 粗黑描边 + 粗圆角，撞色只用在块与按钮
  • 草莓/蓝莓/芒果三色各自主导一类元素，秩序清晰
为何能当默认：硬阴影是纯 CSS 盒阴影（无模糊），渲染便宜；三色分工明确（红=警示/强调、蓝=主操作、黄=信息），不靠颜色单独传意；消费 / 教育 / 工具类产品都能驾驭，且儿童与成人都亲和。
