# Gestalt / Grouping

## Principle

People perceptually organize elements into meaningful groups before reading every detail. Proximity, similarity, common region, continuity, and figure/ground can communicate relationships.

## Trigger

Activate when users cannot tell which elements belong together, when cards feel fragmented, or when unrelated elements appear accidentally grouped.

## Non-designer question

> 哪些内容应该让用户一眼看起来是“同一组”？哪些应该明显分开？

## Decision

Prefer perceptual grouping that matches the information model. Use spacing, alignment, containment, repetition, and visual similarity intentionally.

## Specification implications

- Define spacing between related and unrelated groups.
- Define alignment anchors.
- Use containers only when they clarify grouping; avoid boxes around everything.
- Keep repeated patterns visually consistent.

## Verification

Ask a reviewer to identify relationships without reading labels. If they repeatedly mis-group elements, revise the visual grouping.

## Common failures

- cardifying every element
- using borders where spacing would communicate grouping better
- inconsistent alignment
- equal spacing between related and unrelated items
