# 代表性设计师与设计思想家的理念

> 顶尖团队之上是个人思想家的"元原则"——这些原则对任何端、任何平台都成立，是组件库价值观的最终来源。
> 用法铁律：**提取"原则 → 可执行规范"**，不把名言当装饰引用。

## Dieter Rams（迪特·拉姆斯）— 好设计的十项原则

1. **Innovative**（创新）
2. **Useful**（有用）
3. **Aesthetic**（美观）
4. **Understandable**（易懂）
5. **Unobtrusive**（克制、不显眼）
6. **Honest**（诚实，不虚假承诺）
7. **Long-lasting**（持久，反潮流）
8. **Thorough**（细致到每个细节）
9. **Environmentally friendly**（环保）
10. **Minimal**（少即是多，"Less but better"）

- **组件库表现为**：每个组件要必要、克制、易懂，不添加多余装饰。状态真实反映数据（Honest）；不追潮流频繁改版（Long-lasting）；语义清晰（Understandable）。

## Naoto Fukasawa（深泽直人）— 无意识设计（Without Thought）

- **哲学**：设计应"without thought"——让人无意识、凭直觉就能使用；从日常行为中提炼形式（如壁挂式 CD 播放器，拉绳即播放）。
- **核心概念**：Affordance 的自然化、行为的下意识、产品与环境的无缝。
- **组件库表现为**：组件使用直觉，操作符合用户已有心智模型（滑块即调、开关即 toggle）；减少需要"学习"的控件；把高频操作做成"不用想就会用"，不增加认知负担。

## Kenya Hara（原研哉）— 白、空与留白

- **哲学**："空"不是无，而是容纳内容的容器；留白（negative space）让信息呼吸、凸显本质。
- **核心概念**：Exformation（未言明的信息）、极简版面、物的尊严。
- **组件库表现为**：关注负空间（negative space），让内容呼吸；卡片内边距、区块间距用 token 而非凑满；克制分隔线，用空白分区而非框线。

## Don Norman（唐·诺曼）— 设计心理学与情感化设计

- **核心概念**：Affordances（可供性）、Signifiers（信号/指示）、Mental Models（心智模型）、Mappings（映射）、Feedback（反馈）、Constraints（约束）。
- **可用性工程**：发现 → 理解 → 操作 三阶段必须顺畅。
- **情感化设计三层**：
  - **Visceral（本能层）**：视觉第一印象的愉悦——颜色、圆角、间距、材质符合品牌基调，一眼舒适。
  - **Behavioral（行为层）**：交互流畅——反馈及时、操作顺手、无挫败、状态清晰。
  - **Reflective（反思层）**：长期使用建立的信任与品牌情感——一致打磨的细节让人认同。
- **组件库表现为**：组件命名与图标即是 signifier；操作映射直观（删除按钮带确认）；状态反馈即时；用约束防错；三层都要照顾（好看 + 好用 + 可信）。

## Jakob Nielsen — 10 可用性启发式

1. 系统状态可见
2. 系统与真实世界匹配
3. 用户控制与自由（撤销/重做）
4. 一致性与标准
5. 错误预防
6. 识别优于回忆
7. 灵活高效（快捷键 / 默认值）
8. 极简审美
9. 帮助用户识别 / 诊断 / 恢复错误
10. 帮助与文档

- **组件库表现为**：状态管理（可见性、错误预防）、表单校验、空态 / 加载态 / 错误态的完备性（对应 #1、#5、#9）；组件需提供清晰的反馈状态（hover, active, disabled, loading）。

## Jony Ive（乔纳森·艾维）— 极简与一体化

- **哲学**：通过删减（reduction）达至简单，直到不可再简化；材质与形式的诚实；产品即体验。
- **组件库表现为**：组件要纯粹，去掉视觉噪音；去冗余、隐藏复杂、聚焦内容、减少不必要的层级与边框。

## Susan Kare（苏珊·卡雷）— 图标与视觉语言

- 像素级图标美学、隐喻清晰、克制色彩、网格对齐。
- **组件库表现为**：图标组件库原则——清晰 > 漂亮、网格对齐、语义一致、可识别优先。

## 日本侘寂（Wabi-sabi）— 情感与美学

- **哲学**：不对称、朴素、自然、在不完美中见美。
- **组件库表现为**：不必追求绝对对称与完美；接纳内容的不规则；用自然材质感与留白营造温度；避免过度拟物或过度光鲜。

## 其他

- **Frank Chimero**《The Shape of Design》：设计是建立联系、讲故事。
- **Bruno Munari**：设计既是艺术也是功能，形式是功能的延伸。
- **提炼元价值观**：克制、诚实、易懂、以人为本、形式追随功能、容错。

## 如何把"理念"变成可执行规范

每条理念都要落到具体产出，否则只是装饰性引言：
- Rams 的 "Honest" → 组件的错误态 / 空态必须真实，不假装成功。
- Norman 的 "Feedback" → 每个可操作组件必须有 loading / success / error 反馈。
- Fukasawa 的 "Without Thought" → 控件符合心智模型，默认零学习成本。
- Hara 的 "留白" → 间距 / 内边距一律用 token，不用框线分区。
- Nielsen #4 → 同类组件跨端命名与行为一致。
- Ive 的 "reduction" → 默认隐藏高级选项，按需展开。
- 侘寂 → 留白与不对称带来温度，但不牺牲可用性。
